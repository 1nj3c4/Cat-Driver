## AI was used in the process of developing the driver.


An unsigned driver, used primarily for live-process dumping, PE and .bin reconstructing, Thread Hijacking and all other basic tools for game hacking in games with Ring 0 anti-cheat

As of 6th October 2026 work is suspended, feel free to contribute and harden the driver.


### How to load
Cat-Driver is loaded via [Kd Mapper](https://github.com/TheCruZ/kdmapper)

### Known Issues
BSOD's on most of the calls, depends on the your host machine. **Always test on a Virtual Machine**
